KHALIFSON DATA — FARKON ANDROID APP (FLUTTER)

Wannan shi ne farkon prototype na app:
- Login screen da lambar waya (ba a haɗa OTP/SMS verification ba tukuna).
- Dashboard mai Green & White.
- Zaɓin MTN, Airtel, Glo da 9mobile.
- Zaɓin data bundles.
- Wallet yana nuna ₦0.00 ne kawai a matsayin demo.
- Buy Now ba ya aika data ko karɓar kuɗi tukuna.

YADDA ZA A BUƊE SHI
1. Sanya Flutter SDK da Android Studio a kwamfuta.
2. Cire ZIP ɗin.
3. Buɗe terminal a cikin babban folder ɗin khalifson_data_flutter.
4. Gudanar da: flutter create .
5. Gudanar da: flutter pub get
6. Haɗa Android phone ko buɗe emulator.
7. Gudanar da: flutter run

KAFIN A SAKA A PLAY STORE
Ana buƙatar:
- VTU API account da live API credentials.
- Backend mai tsaro domin kada a saka API secret a cikin app.
- SMS/OTP provider domin tabbatar da lambar waya.
- Payment gateway domin saka kuɗi a wallet.
- Database, admin dashboard, transaction logs da webhook verification.
- Gwaji, privacy policy, support details da Google Play developer account.

MUHIMMI:
Farashin data da ke cikin prototype misali ne kawai. A canza su bisa farashin API ɗin da aka zaɓa.
Kada a yi amfani da wannan demo wajen karɓar kuɗin kwastomomi tukuna.
